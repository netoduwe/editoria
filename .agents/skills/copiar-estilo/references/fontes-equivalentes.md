# Fontes equivalentes livres

Identifique pela anatomia, escolha a equivalente e baixe: `node scripts/baixar-fonte.mjs "<Família>" <pesos> [--italico]`. Todas abaixo estão no Fontsource (licença livre). Se a fonte original for livre (Poppins, Bebas Neue, Montserrat…), use ela mesma.

## Como reconhecer
- **Geométrica** (O redondo, a de um andar em algumas): Montserrat, Poppins, Futura → Jost.
- **Grotesca/neo-grotesca** (neutra, a de dois andares, terminais retos): Helvetica/Arial/SF Pro → Inter, Archivo.
- **Humanista** (traço com modulação leve, aberturas largas): Proxima/Avenir → Figtree, Nunito Sans.
- **Condensada pesada** (alta e estreita, títulos de impacto): Impact/Anton → Anton, Oswald, Bebas Neue.
- **Serifa editorial de alto contraste** (hastes grossas e finas, itálico elegante): Didot/Bodoni/"Instrument" → Instrument Serif, Playfair Display, DM Serif Display, Bodoni Moda.
- **Serifa clássica de livro**: Garamond/Times → EB Garamond, Cormorant Garamond, Libre Caslon Text.
- **Mono/terminal**: SF Mono/Menlo → JetBrains Mono, IBM Plex Mono, Space Mono.
- **Arredondada**: Nunito, Quicksand. **Manuscrita**: Caveat, Permanent Marker. **Pixel**: Press Start 2P, Silkscreen, VT323.

## Tabela rápida
| Na referência parece… | Use |
|---|---|
| "The Bold Font", legenda de Reels gorda | Montserrat 800–900 ou Archivo Black |
| Proxima Nova / Gotham | Montserrat (600–800) ou Figtree |
| SF Pro / Helvetica / Arial / "TikTok Sans" | Inter (600–900) |
| Futura | Jost |
| Avenir / Gilroy | Figtree ou Plus Jakarta Sans |
| Circular | DM Sans |
| Impact / meme | Anton (+ contorno preto) |
| Komika (quadrinho) | Bangers |
| Bebas | Bebas Neue |
| Didot / Bodoni / revista | Playfair Display ou Bodoni Moda |
| Serifa itálica fina "editorial" | Instrument Serif Italic (já no kit) |
| Garamond / Times | EB Garamond |
| Mono de código | JetBrains Mono |

Ajuste fino depois de trocar: compare no `lado-a-lado` a largura de uma palavra igual; corrija tamanho e `letter-spacing` até a mancha do texto bater.
